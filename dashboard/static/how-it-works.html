Step 1 of 3

The producer publishes an event to a named topic.

01 · Topics

Named streams

A topic groups related events. Producers write to it and consumers decide when and how to read it.

02 · Partitions

Parallel logs

Each topic is split into append-only partitions. A key can keep related events together while partitions provide parallelism.

03 · Offsets

Durable progress

Every record has an offset. Consumer groups commit offsets so they can resume from the right place after a restart.
